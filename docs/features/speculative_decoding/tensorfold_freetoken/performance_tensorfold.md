# GB10 性能对照 · TensorFold 0.6.0

A1/A2 为 TensorFold 0.6.0 原生 Tree-DFlash2，保留其原生候选策略和 FP8 prefill。
B 为 vLLM 0.33.0 上的 Tree-DFlash2 K=15，启用批量 GPU 状态提交、长前缀 Graph
和原 2K/C8 分桶，外层 eager。B 的源码树为
`de1f7b4b9d33a5125ea131c69c6dc13d99d8436b`，早于本分支的编译 prefill
和多请求通用分桶。当前源码的单变量 A–B–A 见[合入记录](integration.md)。

## 测试口径

- 在同一张 GB10 串行运行，驱动 580.95.05。A 的本机镜像 ID 为
  `sha256:034aaf3d1c644a2632e959d21a023caba048af0b01e3af7d86d3a63dfa32243f`，
  B 基底为 `vllm/vllm-openai:v0.33.0`，本机镜像 ID 为
  `sha256:a0dfdeea1d42d4201c82d9bb44f2f4bb1ac2ef5aea196e9e0d1007a2834d2f70`。
- 共用 Qwen3.8-27B ModelOpt NVFP4/FP8、同一 DFlash2 草稿、TP1、131072 上下文、
  FP8 KV 和最多 8 请求。按各框架实际启动配置比较整套推理性能。
- 冻结 ShareGPT 提示包 SHA256 为
  `edb3560763e3545978d319a7d88082d1bbb35dbb6f7622bb6623c1b2e7fa4742`。
  输入 2048/8192，输出 1024，seed 11230，贪心解码，忽略 EOS。
  C1 每轮 2 条，C8 每轮 10 条，每格三轮。C1/C8 分别热身 3/8 条，每条热身输出 128。
  三臂共 216/216 正式请求通过配对、长度和服务回执检查。
- TPOT 用末次与首次有效 SSE 输出的时间差除以输出 token 数减一。输出吞吐计入客户端执行全程。
  B 相对 A1/A2 均值计算差异，漂移为两次 A 的绝对差除以该均值。绝对差异超过漂移才判为可分辨。
